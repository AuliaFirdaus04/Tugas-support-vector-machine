# Tugas-support-vector-machine

1. Jumlah dan Pembagian Data:
a). Total Dataset(Customer Mall)
Terdiri dari 200 baris data dan 5 kolom:
 - CustomerID,
 - Gender,
 - Age,
 - Annual Income (k$), 
 - Spending Score (1-100). 

b). Pembagian Data
   - Data Latih (Train – 80%): 160 baris digunakan untuk melatih model SVM dan mencari titik support vector
   - Data Uji (Test – 20%): 40 baris digunakan untuk menguji performa klasifikasi model.

 2. Parameter C Digunakan 4:
    Variasi Nilai parameter regulasi C:
     - C = 0,01
     - C = 0,1
     - C = 1
     - C = 10

  3. Struktur File:
     a). Mall_Customers.csv (file dataset)
     b). Kodingan_Support_Vector_Machine.py (file program Python)
